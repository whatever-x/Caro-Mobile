# 가져오기 파서 테스트 자료

외부 학습 데이터 가져오기 파서(`:core:importparser`)와 연결 후 처리(`:feature:importer`) 테스트가 함께 쓰는 입력 파일과 기대값이다.

- 모든 파일은 직접 만든 합성 자료다. 짧은 영어·한국어·일본어 예시와 `filler00001`, `채움00001` 같은 생성 값만 들어 있고 외부 단어장, 공유 덱, 저작물은 없다. 이미지(1x1 PNG)와 음성(무음 WAV)도 코드로 만들었다.
- `expected/<형식>/<파일>.json`은 설계 규칙에서 손으로 계산한 기대값이다. 구현 결과를 옮겨 적은 값이 아니므로 테스트가 실패하면 구현을 먼저 의심한다.
- `apkg/large_10001_notes_legacy.apkg`는 최신 형식 대용량 파일과 내용이 같아 저장소 크기를 줄이려고 넣지 않았다.
- 100MB 초과 파일(`oversize_over_100mb.tsv`)은 만들지 않는다. 크기 차단은 작은 `maxFileBytes` 값으로 검증한다.
