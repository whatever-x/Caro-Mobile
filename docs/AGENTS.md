# 프로젝트 문서 관리 지침

`docs/`는 Caro-Mobile의 구조·설계 규칙과 개발·검증·운영·협업 절차를 관리하는 프로젝트 문서 디렉토리입니다.

모듈 책임과 의존 관계, Android·iOS 구성, 개발 환경과 빌드, 테스트, CI 운영, Git 협업 규칙을 문서화합니다.
프로젝트를 이해하고 작업을 수행하는 데 필요한 기준·설정·명령·확인 방법을 작성합니다.

코드·설정·작업 절차가 변경되어 기존 설명과 달라지면 관련 문서를 함께 갱신합니다.
이 지침은 해당 문서를 작성·수정·재배치할 때 적용합니다.

## 문서 분류와 배치

- 문서의 분류와 위치는 [문서 탐색 목록](index.md)에서 확인합니다.
- 문서는 성격에 맞는 하위 디렉토리로 묶어 관리합니다.
- 기존 문서에서 다루는 주제는 해당 문서에 반영합니다. 별도 주제를 다룰 때 새 문서를 추가합니다.

## 문서 작성 규칙

- 문서 앞부분에 목적과 적용 상황을 명시합니다.
- 명령·설정 키·파일명·경로는 실제 코드와 설정에 맞춥니다.
- 같은 설명이나 규칙은 원본 문서에서 관리하고, 다른 문서에서는 원본으로 연결합니다.
- 문서를 추가·이동·삭제하거나 제목을 변경하면 관련 링크·앵커·탐색 목록을 갱신합니다.

## 변경 후 확인

- [ ] 설명·명령·설정·파일 경로가 현재 프로젝트와 일치하는지 확인합니다.
- [ ] 링크와 앵커가 올바른 대상으로 연결되는지 확인합니다.
- [ ] 문서의 분류와 탐색 목록이 변경 사항을 반영하는지 확인합니다.
- [ ] 공유할 문서의 Git 제외 여부를 확인합니다.
- [ ] `git diff --check`를 실행합니다.

## 가드레일

- 에이전트 설정·스킬·훅 문서는 `docs/`에 중복 작성하지 않습니다. [에이전트 설정 관리 지침](../.agents/AGENTS.md)을 따릅니다.
- 개인 설정·자격증명·작업 기록·임시 계획은 공유 문서에 포함하지 않습니다.
