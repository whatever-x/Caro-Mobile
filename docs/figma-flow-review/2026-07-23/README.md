## 확인 방법

1. Figma의 `8. 전체 동선 Prototype QA` 페이지를 연다.
2. 확인할 섹션의 첫 번째 `[QA]` 프레임을 선택한다.
3. Present를 실행한다.
4. 화면에 표시된 실제 CTA, 카드, 아이콘을 클릭한다.
5. `02 / 자동 로그인 및 세션 만료`의 세션 만료는 Home 하단의 `QA 세션 만료` 버튼으로 재현한다.

## 연결하면서 함께 손본 부분

- 카드 생성은 `0장 추가됨` 상태 대신 저장 가능한 `1장 추가됨` 상태로 교체했다.
- 카드 일괄 삭제는 0개 선택 상태 대신 1개 선택 상태로 교체했다.
- 카드 일괄 삭제에 삭제 확인 다이얼로그와 확인 취소 경로를 추가했다.
- 일일/전체 학습에 완료 경로뿐 아니라 중단과 계속 학습 경로도 연결했다.

## 앱과 다른 부분

Figma와 현재 앱 동작이 다른 곳은 아래와 같다. 이 PR에서는 디자인을 바꾸지 않고, 앱에서 맞춰야 할 항목으로 남겼다.

| Figma에서 정의한 흐름 | 현재 앱 동작 |
|---|---|
| 신규 로그인 → 프로필 생성 → Home | 로그인 성공 시 바로 Home으로 이동한다. |
| 덱 카드 탭 → 카드 상세 → 수정/삭제 | 카드 상세 화면 없이 카드 수정으로 바로 이동한다. |
| 보호 화면에서 인증 세션 만료 → Login | Splash 이외 화면의 세션 만료 처리가 TODO로 남아 있다. |
| 덱 삭제 확인 → 삭제 완료 → Home | 덱 삭제를 선택해도 바텀시트만 닫힌다. |
| 전체 학습을 시작할 때 카드 셔플 | 저장된 카드 목록 순서를 그대로 사용한다. |
