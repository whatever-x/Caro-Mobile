# 에이전트 설정 관리 지침

`.agents/`의 공유 설정·훅·스킬과 관련 문서를 작성하거나 수정할 때 적용합니다.
공통 작업 규칙과 검증 절차는 루트 [AGENTS.md](../AGENTS.md)를 따릅니다.

- 설치·등록·활성화는 사용 중인 에이전트의 공식 지침을 따릅니다.
- 파일을 추가·이동·삭제하거나 이름을 변경하면 관련 링크·탐색 목록을 갱신합니다.
- 변경 후 해당 패키지에서 요구하는 검사를 실행합니다.

## 훅

- 훅 원본과 관련 파일은 `hooks/<hook-name>/`에서 관리합니다.
- 훅 설치·설정 관리 시 [훅 탐색 목록](hooks/index.md)에서 필요한 패키지를 찾고 해당 사용 지침을 읽습니다.
- 설치 후 동작과 후속 작업은 [훅 동작 지침](hooks/AGENTS.md#훅-동작과-후속-작업)을 따릅니다.
- 작성·수정 시 [에이전트 훅 관리 지침](hooks/AGENTS.md#훅-작성-규칙)을 따릅니다.
- 설치 방법은 [설치 지침](hooks/AGENTS.md#훅-설치-방법)을 확인합니다.

## 스킬

- 스킬 원본과 관련 파일은 `skills/<skill-name>/`에서 관리합니다.
- [스킬 탐색 목록](skills/index.md)에서 작업에 맞는 스킬을 선택하고 해당 `SKILL.md`를 읽습니다.
- 작성·수정 시 [에이전트 스킬 관리 지침](skills/AGENTS.md#스킬-문서-작성-규칙)을 따릅니다.
- 설치 방법은 [설치 지침](skills/AGENTS.md#설치-방법)을 확인합니다.

## 금지사항

- 프로젝트 구조·기술·개발·CI 문서를 `.agents/`에 중복 작성하지 않습니다. [프로젝트 문서](../docs/index.md)로 연결합니다.
- 같은 규칙을 여러 문서에 복사하지 않습니다. 원본 문서로 연결합니다.
- 파일이 저장소에 있다는 이유로 자동 로딩·호환성·활성화를 가정하지 않습니다.
- 개인 설정·로컬 등록본·자격증명·작업 기록·임시 계획은 공유 대상에 포함하지 않습니다.
