# 에이전트 스킬

Caro-Mobile에서 공유하는 에이전트 스킬 모음입니다. Compose·Kotlin·KMP 코드 구현과 리뷰, API 동기화 등에 필요한 작업 절차와 참고 파일을 패키지별로 관리합니다.

**이 README는 사용자(개발자)가 읽는 소개·설치 안내입니다.** 에이전트용 관리 규칙은 `AGENTS.md`, 작업별 지침은 각 패키지의 `SKILL.md`에서 관리합니다.

## 설치와 사용

1. 사용 중인 에이전트의 공식 스킬 안내에서 지원 조건·발견 경로·설치 위치·호출 방식을 확인합니다.
2. 각 패키지의 `SKILL.md`에서 목적과 적용 조건을 확인합니다. 현재 스킬들은 Caro-Mobile의 KMP·Compose·모듈 구성을 전제로 합니다.
3. 스킬 간 상대 참조가 있으므로 전체 묶음을 기본으로 설치합니다. 일부만 설치할 때는 참조하는 형제 스킬도 함께 준비합니다.
4. 공식 설치 방식에 따라 프로젝트 로컬 또는 사용자 영역에 설치합니다. 이 디렉토리의 스킬을 직접 발견하는 환경에서는 공유 원본을 사용할 수 있습니다.
5. 실제 에이전트 세션에서 스킬 목록과 로딩 여부를 확인하고, 공식 안내의 호출 방식으로 필요한 스킬을 사용합니다.

이 디렉토리는 공유 원본을 보관합니다. 원본은 유지하고, 별도 설치본은 원본이 변경되면 함께 갱신합니다. 개발자별 로컬 설치본·개인 설정·자격증명은 Git 공유 대상에서 제외하며, 자격증명은 설치·배포 패키지에도 포함하지 않습니다.

## 패키지 구조

스킬마다 `<skill-name>/` 디렉토리를 사용합니다. 아래는 공통 구조를 설명하는 예시이며, 보조 디렉토리는 필요한 경우에만 둡니다.

```text
skills/
├── README.md                 # 사용자용 소개·설치 안내
├── AGENTS.md                 # 에이전트용 스킬 관리 지침
├── index.md                  # 에이전트용 스킬 탐색 목록
└── <skill-name>/
    ├── SKILL.md              # 스킬 메타데이터·작업 절차
    ├── reference/            # 선택: 상세 참고 문서
    ├── examples/             # 선택: 사용·적용 예제
    └── scripts/              # 선택: 실행 스크립트
```
