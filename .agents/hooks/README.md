# 에이전트 훅

Caro-Mobile에서 공유하는 에이전트 훅 패키지 모음입니다. 작업 목적에 따라 여러 훅을 추가할 수 있으며, 각 훅은 독립된 패키지에서 설정 원본·사용 지침·레퍼런스를 관리합니다.

이 문서는 모든 훅의 공통 설치 방법과 패키지 구조를 소개합니다. 훅별 적용 조건과 읽을 문서는 각 패키지의 `<hook-name>.md`에서 확인합니다.

## 설치 방법

1. 각 패키지의 `<hook-name>.md`에서 적용 조건을 확인해 설치할 훅을 선택합니다.
2. 선택한 패키지에서 필요한 설정·동작 레퍼런스를 읽습니다.
3. 사용 중인 에이전트의 공식 훅 지침으로 지원 여부·등록 위치·입출력 호환성을 확인합니다.
4. 필요한 설정을 에이전트의 프로젝트 로컬 또는 사용자 영역에 등록하고 공식 지침에 따라 활성화 상태를 확인합니다.

설치·활성화된 훅은 에이전트가 등록된 이벤트에 따라 자동으로 호출하고, 감지 조건에 맞으면 설정된 처리를 수행합니다. 작업마다 훅을 다시 선택할 필요는 없습니다. 에이전트에게 전달되는 후속 안내와 실행할 작업은 해당 패키지의 사용 지침을 따릅니다.

이 디렉토리는 공유 원본을 보관합니다. 원본은 이동하지 않습니다. 루트 `.codex/`·`.claude/`의 개발자별 로컬 등록본은 Git에서 제외하며, 원본이 변경되면 등록본도 갱신합니다. 체크아웃만으로 훅이 등록되거나 활성화되지는 않습니다. 훅별 실행 조건·사용자 승인·가드레일은 해당 패키지의 사용 지침을 따릅니다. 여러 훅을 등록할 때는 기존 설정을 보존하고 같은 훅을 중복 등록하지 않습니다.

## 패키지 구조

훅마다 `<hook-name>/` 디렉토리를 추가합니다. 아래는 공통 구조를 설명하는 예시이며, 실제 설치된 훅 목록은 아닙니다.

```text
hooks/
├── README.md                 # 사람을 위한 공통 소개·사용 안내
├── AGENTS.md                 # 에이전트 훅 관리 지침
├── index.md                  # 에이전트의 설치·설정 관리용 훅 탐색 목록
├── <hook-name>/
│   ├── <hook-name>.json       # 훅 설정 원본
│   ├── <hook-name>.md         # 적용 조건·사용 지침
│   └── references/           # 상세 설정·동작·검사
└── <another-hook-name>/      # 다른 목적의 훅도 같은 구조로 추가
```

훅을 추가하거나 수정할 때는 [에이전트 훅 관리 지침](AGENTS.md)을 따릅니다. 새 패키지의 적용 조건과 사용 방법은 해당 패키지의 `<hook-name>.md`에 작성합니다. 자격증명과 개인 파일이 Git 등록 대상에 포함되지 않는지 확인합니다.
